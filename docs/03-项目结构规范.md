# 项目结构规范

```text
backend/        FastAPI 应用；api、schemas、services、repositories、domain、tasks
frontend/       Vue 应用；views、components、stores、services、types
docs/           本规范与 ADR
data/           本地运行数据（原始导入、SQLite、导出）；不得提交私密数据
docker/         镜像、编排与部署配置
scripts/        可重复执行的运维、导入和初始化脚本
models/         模型配置、下载说明；不提交大模型权重
rag/            切块、嵌入、检索与评估实现
tests/          unit、integration、e2e、fixtures
```

依赖方向：`api → services → domain/repositories`；`tasks → services`；`rag → domain/repositories`。`domain` 不依赖框架、ORM、LLM 或 HTTP。前端 `views → components/stores/services`，不得在组件中复制业务规则。

一个模块只负责一个领域：菜谱、食材、库存、采集、检索、推荐和会话应各自拥有服务与测试。跨领域协调放在应用服务，不得通过互相查询数据库实现。密钥只存在环境变量或未提交的本地配置中。
