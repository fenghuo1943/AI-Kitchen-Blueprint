# 前端规范

使用 Vue 3 Composition API、TypeScript strict、Vite、Vue Router、Pinia。页面分为：菜谱发现、库存、推荐、知识库问答、内容管理；聊天与管理采用独立路由及状态域。

组件只负责展示和交互，API 调用集中在 `services`，跨页面状态在 Pinia，类型与后端 Schema 同步维护。禁止把推荐评分、食材规范化等领域规则复制到前端。表单必须展示字段级校验；异步操作必须有加载、空态、失败重试和成功反馈。

推荐卡至少呈现：标题、图片占位/图片、用时、难度、命中食材、缺少食材和“为什么推荐”。问答界面显示证据菜谱链接；内容管理显示任务状态和具体错误。可访问性基线：键盘可操作、可见焦点、语义标签、颜色不是唯一信息载体；移动端优先保证浏览、库存录入和推荐流程。

## 页面建议结构

- `菜谱发现页`：支持列表浏览、筛选、搜索、标签切换和详情查看。
- `库存页`：支持新增/编辑/删除库存项、查看保质期和快捷推荐。
- `推荐页`：支持输入食材、约束条件和目标，并展示推荐结果与理由。
- `问答页`：显示问题输入、证据菜谱和回答来源。
- `内容管理页`：显示草稿、审核中、已发布和失败任务的状态。

## 推荐卡字段

每张推荐卡至少包含：
- `title`
- `prep_minutes` / `cook_minutes`
- `difficulty`
- `matched_ingredients`
- `missing_ingredients`
- `reason`
- `source_label`

## 交互要求

- 推荐结果加载时显示骨架加载态；无结果时给出明确提示。
- 失败请求必须显示可重试操作，而不是空白页面。
- 所有表单必须提供字段级校验和提交失败反馈。

## 响应式设计规范

### 断点定义

| 设备类型 | 断点范围 | 说明 |
|---------|---------|------|
| 移动端 | < 768px | 手机设备 |
| 平板端 | 768px - 1024px | 平板设备 |
| 桌面端 | > 1024px | 桌面电脑 |

### 响应式工具

项目提供 `useResponsive` 组合式函数，用于检测当前设备类型：

```typescript
import { useResponsive } from '../composables/useResponsive';

const { isMobile, isTablet, isDesktop } = useResponsive();
```

**使用场景：**
- 条件渲染不同的组件布局
- 动态切换导航模式
- 根据设备类型调整交互行为

### 布局规范

#### 导航栏
- **移动端**：汉堡菜单 + 侧边栏导航
- **桌面端**：水平导航栏

#### 表单布局
- **移动端**：垂直堆叠布局
- **桌面端**：水平并排布局

#### 卡片网格
- **移动端**：1-2列网格
- **平板端**：2列网格
- **桌面端**：3-4列网格

#### 模态框
- **移动端**：底部弹出，接近全屏
- **桌面端**：居中弹窗

### 触摸友好设计

- 所有可点击元素最小高度：44px
- 按钮内边距：至少 10px
- 表单输入框使用 16px 字体（防止 iOS 自动缩放）
- 确保足够的触摸目标间距

### CSS 媒体查询示例

```css
/* 移动端 */
@media (max-width: 767px) {
  .container {
    padding: 16px;
  }
  
  .form-row {
    flex-direction: column;
  }
}

/* 平板端 */
@media (min-width: 768px) and (max-width: 1023px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 桌面端 */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

### 组件响应式实现

#### App.vue
- 移动端：汉堡菜单控制侧边栏显示/隐藏
- 使用 `useResponsive` 检测设备类型
- 点击菜单项后自动关闭移动端菜单

#### 页面组件
- 使用 CSS 媒体查询调整布局
- 表单行在移动端垂直堆叠
- 操作按钮在移动端全宽显示
- 卡片内容在移动端紧凑显示

### 测试要求

- 使用浏览器开发者工具模拟不同设备尺寸
- 在真实移动设备上测试触摸交互
- 验证所有页面在 375px（iPhone SE）到 1920px 宽度下的显示效果
- 确保表单输入不会触发 iOS 自动缩放
