# AI Kitchen Assistant V2 开发文档

## 项目目标

构建**本地优先**的 AI 家庭厨房助手：沉淀可信菜谱知识库，并根据现有食材、季节、饮食偏好、烹饪条件和目标（如快速、控脂、暖胃）推荐可执行菜谱。系统的推荐依据必须可追溯到结构化数据或知识库来源。

## 文档使用约定

开始任何开发、数据导入或架构调整前，须完整阅读本目录。文档按以下顺序使用：

1. `01`～`04`：产品目标、架构与目录边界。
2. `05`～`08`：数据、知识库、模型和推荐核心。
3. `09`～`13`：接口、前端、代码、提示词与研发流程。
4. `14`～`17`：实施计划、演进方向、采集入库和验收标准。

发生冲突时，优先级为：ADR → 数据字典/API 规范 → PRD → 其他规范。涉及总体架构的变更必须新增 ADR，不得静默修改既有决策。
