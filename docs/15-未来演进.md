# 未来演进

以下内容不属于 MVP，只有在核心菜谱质量、推荐准确性和本地体验达标后再立项。

1. **多家庭与同步**：多账户、家庭成员、加密同步、权限隔离和冲突解决。
2. **智能采集**：OCR 识别纸质菜谱/小票，图片理解食材与成品；所有自动结果仍需审核后发布。
3. **家庭设备连接**：通过 Home Assistant 获取可选的设备状态与计时提醒；设备控制需单独安全模型和显式确认。
4. **Agent 与 MCP**：在受限工具、可审计计划和用户确认的前提下，协助生成采购清单、安排备餐；不得自行下单或修改关键数据。
5. **采购与营养扩展**：对接区域化商品/价格、营养数据库和菜单计划，必须标明数据来源、更新时间与不确定性。
6. **平台化部署**：PostgreSQL、多租户、对象存储、任务队列、可观测性和模型网关。

每一项演进需先补 ADR 与威胁建模，验证不会破坏本地优先、可追溯和无云可用的核心承诺。

## 前端响应式演进

### 已完成

1. **响应式工具**：创建 `useResponsive` 组合式函数，提供设备类型检测
2. **导航栏适配**：移动端汉堡菜单 + 侧边栏导航
3. **页面布局适配**：所有页面支持移动端、平板端和桌面端
4. **触摸友好设计**：按钮最小高度 44px，输入框 16px 字体

### 未来优化

1. **PWA 支持**：添加 Service Worker，支持离线访问和添加到主屏幕
2. **手势交互**：支持滑动删除、下拉刷新等移动端手势
3. **深色模式**：根据系统设置或用户偏好切换深色/浅色主题
4. **性能优化**：图片懒加载、虚拟滚动、代码分割
5. **无障碍增强**：ARIA 标签、屏幕阅读器支持、高对比度模式
6. **国际化**：多语言支持，适配不同地区的阅读习惯
