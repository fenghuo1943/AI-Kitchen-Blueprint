# PRD：AI 家庭厨房助手 MVP

## 用户与场景

- 家庭做饭者：录入冰箱食材，寻找能做且少缺料的菜。
- 注重饮食的人：按季节、口味、烹饪时长、忌口或目标筛选菜谱。
- 内容维护者：采集、校对、发布菜谱，并查看导入失败原因。

## MVP 功能

1. 菜谱库：浏览、搜索、查看标准化食材、步骤、时长、标签、来源和修订时间。
2. 库存：手工增删食材、数量/单位、保质期和备注；可标记已有或缺少。
3. 推荐：输入食材或从库存选择，叠加季节、人数、时长、设备、忌口和目标，返回排序菜谱及理由。
4. AI 问答：只基于已发布菜谱回答“怎么做、能否替换、还缺什么”；无法依据知识库回答时明确说明。
5. 内容入库：导入结构化文件或审核后的网页采集结果，支持草稿、校验、发布和重建索引。
6. 响应式设计：支持移动端、平板端和桌面端自适应布局，确保在不同设备上都能正常使用。

## 成功标准

对具备至少一种核心食材的查询，返回结果能说明命中与缺失；已发布菜谱可在索引完成后被检索；无网络和无云模型时，浏览、库存、规则推荐仍可用。

## 非目标

MVP 不做社区、短视频、外卖下单、自动医疗/营养诊断、无人审核的全网批量抓取，也不承诺精确营养医疗结论。
